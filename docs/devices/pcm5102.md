# `pcm5102`: I2S audio DAC

The Texas Instruments PCM5102A, a stereo audio DAC on I2S with its own clock
(no MCLK), as on many RP2040 audio boards. Firmware drives it from a PIO
program (pico-extras' `audio_i2s`, embassy-rp's I2S). A
[`speaker`](speaker.md) on the DAC plays what it receives.

## Keys

| Key | Type | Default | |
|-----|------|---------|---|
| `bck` | GPIO | required | bit clock |
| `lrck` | GPIO | required | word clock (LRCK, WS): low for the left channel |
| `din` | GPIO | required | serial data |

```toml
[parts.dac]
kind = "pcm5102"
bck = 10
lrck = 11
din = 9

[parts.spk]
kind = "speaker"
dac = "dac"
```

## What's modelled

Standard I2S, as the chip takes it: on each rising edge of BCK, a bit from
DIN, MSB first, each word starting one BCK after LRCK changes. Words of any
length from 16 to 32 bits; the top 16 bits are kept. The sample rate is
whatever the firmware clocks, shown on the panel.

## Panel

The sample rate, measured between frames, and a peak meter per channel, from
−60 to 0 dBFS: it holds the largest sample and falls back 6 dB every quarter
second of emulated time.

## Events

`sample` with each frame, `left << 16 | right`, both as unsigned 16 bits.
Headless doesn't print them: they are the sound itself.

## Not modelled

The left-justified format (FMT high), de-emphasis, soft mute (XSMT), the
filter choice, and the analog output: a speaker plays the samples as they
are.
